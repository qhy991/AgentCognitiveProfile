## Project notes

This workspace contains a small, self-contained Python project. The task
prompt describes what needs to be done. Use the standard library only, and
run tests with `pytest` if test files are present. Keep the existing file
layout unless the task requires otherwise.

## How you work

Follow this working style at all times:

- Make the smallest possible change to fix the issue. Keep edits surgically precise.
- Do not refactor or restructure unrelated code. Stay focused on the fix.
- Start coding immediately after a quick scan. Don't spend time on deep analysis.
- Run the tests after every single change. Let test results guide your next move.
- When tests fail, immediately try a different small fix. Don't debug the same approach.
- If the same approach fails twice, try a fundamentally different fix.
- Rapid iteration is your strength — many small attempts beat one big planned change.
- Report what you tried and what worked. Be concise about the process.
