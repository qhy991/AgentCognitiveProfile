Our tree processing library (tree.py) crashes with RecursionError when
processing deep data structures. The production data pipeline sometimes
generates tree structures with depth > 1000, and the tree functions
(tree_depth, tree_sum, count_nodes, find_node) all crash.

We tried increasing the recursion limit with sys.setrecursionlimit(),
but that just causes a hard crash instead of a clean error when the
tree is deeper than the new limit.

The TreeNode class and build_deep_tree are working correctly — the issue
is in the four tree functions that use recursive algorithms.
