Agent 认知画像 — 三维性能空间

8 种认知画像 × 5 个任务 × 3 次重复 = 120 次运行 | 多维度评分（正确性 + 代码改动量 + 代码质量）

认知画像三维空间说明

每个 Agent 的认知风格由三个独立维度定义，每个维度取 0 或 1，共 2³ = 8 种组合。每个维度对应 CLAUDE.md 中的具体行为指令，而非人格标签。

轴 1：探索程度（Exploration）

决定 Agent 在解决问题时倾向于最小改动还是探索多种方案。

0 = 保守
最小改动，不重构，保持现有模式 1 = 探索
考虑多种方案，愿意重构，探索代码库

轴 2：思考-行动偏好（Thinking）

决定 Agent 是先全局分析再动手，还是先动手再从反馈中学习。

0 = 行动优先
直接动手，从测试反馈中迭代学习 1 = 思考优先
先读全部代码，制定计划，再按计划执行

轴 3：反馈适应能力（Adaptation）

决定 Agent 在测试失败或遇到新信息时是否调整策略。

0 = 坚持己见
信任初始判断，不轻易改变方向 1 = 灵活适应
根据测试结果主动调整策略和假设

为什么 (0,0,0) 保守实干家 和 (1,1,1) 全面创新者 得分接近？

两者在三维空间中处于完全对立的角落（一个是 (0,0,0)，一个是 (1,1,1)），但综合得分仅差 4%（88% vs 84%）。 这说明：在小型任务上，不同的认知策略可以达到相似的结果，但代价不同。

结论：虽然两者都能完成任务，但 保守实干家 (0,0,0) 以更低的成本达到了相同甚至更好的结果。 全面创新者 (1,1,1) 的"先全局分析、探索多种方案、动态调整"策略在小型任务上属于过度投入。 这验证了 Task-Profile Alignment 假设：不同任务需要不同的认知画像，不存在"万能最优"画像。

关键发现

  1. 保守实干家 (0,0,0) 综合最优：综合得分 88%，代码改动最少（59%），对话轮次最少（12.5），成本最低（$0.52）。"只改必须改的"策略在小型任务上最有效。
  2. 完美架构师 (1,1,0) 成本最高：对话轮次最多（18.7），成本最高（$0.71），叙述文字量是 p000 的 2.6 倍。但正确性同样是 100%。"先全局分析再动手"的策略增加了过程成本而非结果质量。
  3. 思考优先（T=1）的画像叙述文字量显著更高：p010（1833）、p110（2451）、p111（1942）都远超行动优先的画像，验证了"思考-行动"轴的行为指令有效性。
  4. 探索（E=1）的画像改动更多：p100-p111 的 minimality 普遍低于 p000-p011，说明探索型 Agent 倾向于做更多代码修改。
  5. 多维度评分是唯一有效区分方法：二元通过/失败评分下 218 次运行全部满分（区分度 0%），多维度评分下 120 次运行全部产生连续分数（区分度 100%）。
